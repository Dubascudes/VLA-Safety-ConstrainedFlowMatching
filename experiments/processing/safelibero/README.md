# Live SafeLIBERO evaluation

Edit `live_viewer.py` here, then reconstruct a new runtime. The materializer installs it as `openpi/examples/safelibero/eval_safelibero_visualized.py`, alongside the reusable `proprioception.py` overlay.

Changing the viewer requires updating the release hash manifest. Do not overwrite the original source manifest. The viewer supports interactive changes but does not yet persist a complete per-episode configuration/intervention ledger.
